# Today

Work with a date on it, across every client. **Derived** - tasks live inside the note that
explains them, so picking one up cold gives you the context for free.

> [!info] How this differs from [[Now]]
> `Now` is about **state**: what is stuck and on whom. `Today` is about **work**: what has a
> date on it. A thing can be on both - blocked on Molly *and* due Thursday.

## Overdue

```tasks
not done
due before today
sort by due
group by folder
```

## Today and tomorrow

```tasks
not done

```

## This week


## Later

Dated, but beyond this week. Here so nothing with a date can fall between sections.

```tasks

```

## No date on it

Work that exists but has never been scheduled. Worth a glance weekly - things live here
indefinitely if nobody looks.

```tasks
not done
no due date
group by folder
```
